# BillyBot

A Discord music/sound bot written with discord.js. Originally built ~2021; an overhaul is planned.

## Setup

1. `npm install`
2. Copy `config.example.json` to `config.json` and fill in the bot token and command prefix.
3. Install [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) and make sure it's on your `PATH` (used to download audio).
4. `node BillyBot.js`

`BillyBot_legacy.js` is the older version of the bot, kept for reference.
